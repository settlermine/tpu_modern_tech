## Лабораторная работа 8 — «Видеотека»

План реализации (выполняем последовательно):

1. Пользовательская страница с постраничным просмотром видео и возможностью отмечать «нравится / не нравится».
2. Пользовательская страница с фильтрацией видео по темам.
3. Административная страница для просмотра полного каталога видео, включая скрытые записи.
4. Административная страница для добавления и удаления видео.
5. Административная страница для отображения рейтинга видео.
6. Возможность протоколирования действий пользователя в файл (текстовый, XML или JSON) и просмотр журнала в административном интерфейсе (табличный вид с датой, временем, действием).
7. Защита всех административных страниц парольным доступом.
8. Демонстрация практических навыков отладки (точки останова, контроль/изменение состояния переменных и т.д.) в среде разработки и тестирования.
