# Лабораторные работы по курсу "Современные платформы программирования"

## Описание проекта

Веб-приложение для управления видеотекой на базе Django. Проект реализует систему просмотра видео с возможностью оценки (лайки/дизлайки), фильтрации по темам, административного управления и протоколирования действий пользователей.

## Технологический стек

- **Python** 3.x
- **Django** 5.2.8
- **SQLite** (база данных)
- **HTML/CSS** (шаблоны и стили)

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Применение миграций

```bash
cd src
python manage.py migrate
```

### 3. Создание суперпользователя (для доступа к админ-панели)

```bash
python manage.py createsuperuser
```

### 4. Заполнение тестовыми данными (опционально)

```bash
python manage.py fill_test_data
```

### 5. Запуск сервера разработки

```bash
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

## Функциональность

Проект реализует полнофункциональную систему управления видеотекой с разделением на пользовательскую и административную части.

### Пользовательская часть

- **Просмотр видео**: постраничный вывод списка видео с превью-изображениями и ссылками на источники
- **Оценка видео**: возможность ставить лайки и дизлайки авторизованным пользователям, с отображением текущих оценок и счетчиков
- **Фильтрация по темам**: выбор одной или нескольких тем для фильтрации списка видео с сохранением выбранных фильтров при навигации
- **Аутентификация**: система входа и выхода с логированием действий

### Административная часть

- **Управление видео**: добавление, редактирование и удаление видео через Django Admin с поддержкой скрытых видео
- **Управление темами**: создание и редактирование тем для категоризации видео
- **Просмотр рейтинга**: отображение статистики лайков и дизлайков для каждого видео с возможностью просмотра детальной информации об оценках
- **Просмотр логов**: административная страница для просмотра всех действий пользователей в табличном виде с фильтрацией и поиском
- **Защита доступа**: все административные страницы защищены парольным доступом через систему аутентификации Django

### Система логирования

Все действия пользователей автоматически протоколируются в трех форматах одновременно:
- Текстовый формат (`.text`) - простой читаемый лог
- XML формат (`.xml`) - структурированные данные
- JSON формат (`.jsonl`) - JSON Lines для программной обработки

Логи сохраняются в отдельные файлы по датам и содержат информацию о времени (с миллисекундами), пользователе и выполненном действии.

## Модели данных

### Video
- `title` - название видео
- `preview_image_url` - URL превью-изображения
- `source_url` - URL источника видео
- `is_hidden` - флаг скрытости видео
- `topics` - связи с темами (ManyToMany)
- `created_at`, `updated_at` - временные метки

### Topic
- `name` - название темы
- `slug` - URL-слаг для фильтрации
- `created_at` - дата создания

### VideoRating
- `video` - ссылка на видео
- `user` - ссылка на пользователя
- `rating_type` - тип оценки ('like' или 'dislike')
- `created_at` - дата создания
- Уникальное ограничение: один пользователь может оценить видео только один раз

### UserActionLog
- `user` - ссылка на пользователя (может быть NULL для анонимных)
- `action` - описание действия
- `timestamp` - дата и время действия

## Основные URL-маршруты

- `/` - список видео с фильтрацией и пагинацией
- `/video/<id>/like/` - поставить/снять лайк
- `/video/<id>/dislike/` - поставить/снять дизлайк
- `/login/` - страница входа
- `/logout/` - выход из системы
- `/admin/` - административная панель Django

## Настройки

Основные настройки в `src/conf/settings.py`:

- `VIDEO_PAGINATION_SIZE = 8` - количество видео на странице
- `LOG_DIR` - директория для файлов логов (по умолчанию `logs/`)
- `LOG_FORMATS = ['txt', 'xml', 'json']` - форматы логирования
